# esaKITs A-5 絵教材 Presenter

**Picture Material Presenter for Japanese Language Teaching**  
公開β版: **v0.8.7**

日本語教育の授業で、絵教材・PDF・画像を読み込み、答え、かな／漢字、活用形、アクセント、無声化情報などを提示するためのブラウザベース教材提示ツールです。

![esaKITs A-5 絵教材 Presenter](docs/screenshot.png)

## 特徴

- PDF・画像・ZIP・CSVの読み込み
- 1ページ／1画像を1カードとして授業提示
- ひらがな／漢字／漢字＋ルビの切り替え
- 動詞・形容詞の活用形表示
- 日本語アクセント表示
  - 核表示
  - 曲線表示
  - 核＋曲線
  - 動詞・形容詞の 0／−2 表示
- 無声化対象モーラの点線丸囲み表示
- フォント、文字色、文字サイズ、太さ、表示位置等の調整
- 対応ブラウザでPC内フォントを読み込み、一覧から選択
- 教師用表示と学習者用書き出し
- ローカル保存（IndexedDB）
- UniDic `lex.csv` を利用した語彙・用言情報の補完
- β課デモ教材を内蔵

## すぐ試す

GitHub Pagesで公開した場合は、公開URLを開くだけで利用できます。

ローカルでは `index.html` をブラウザで開いて利用できます。ただし、PDF表示ではPDF.jsをCDNから取得するため、通常はインターネット接続が必要です。PC内フォントの読み込み機能は、ブラウザの対応状況と権限設定に依存します。GitHub PagesのようなHTTPS環境での利用を推奨します。

### β課デモ

画面の教材メニューから **β課** を開くと、10枚のデモ教材をすぐに確認できます。アクセント表示、無声化表示、動詞・形容詞の形表示など、A-5の主要機能を試せます。

β課の対応データは [`demo_beta/beta_lesson_list.csv`](demo_beta/beta_lesson_list.csv) にあります。

## 基本操作

1. PDF、画像、ZIP、CSVを画面へドラッグ＆ドロップするか、教材メニューから読み込みます。
2. ［表示内容］で、ひらがな／漢字、活用形、アクセント、無声化など「何を見せるか」を設定します。
3. ［表示］で、フォント、文字色、大きさ、位置など「どう見せるか」を設定します。
4. 授業中は［答え］、［次の形］、［アクセント］等の操作で提示を切り替えます。

## アクセント表示

アクセント情報は、原則として**かな表示時のみ**描画します。

- 名詞・な形容詞：核位置または無核情報を表示
- 動詞・い形容詞：0／−2型を語の直後に表示可能
- 動詞のます形：A-5の授業表示では一律 −2 として扱う設定
- 曲線は核表示と別色で、基本的に「へ」のような滑らかな山形で表示

## 無声化表示

無声化は「実際に無声化した」と断定するものではなく、教材上の**無声化対象／無声化環境**を示す情報として扱います。

標準表示は、対象モーラを**点線の丸で囲む方式**です。文字色に依存せず、アクセント表示と同時に利用できます。

## UniDic

A-5本体にはUniDic辞書データを同梱していません。利用者が国立国語研究所の公式UniDicを取得し、`lex.csv` をA-5に読み込ませます。

A-5は主に `orthBase / cType / lForm / aType` を参照し、必要な情報を端末内で索引化します。

## データとプライバシー

読み込んだ教材ファイルをA-5自身が外部サーバーへアップロードする機能はありません。教材管理と設定はブラウザ内で処理します。

PDF表示のためPDF.jsをCDNから読み込む場合など、外部ライブラリ取得の通信は発生します。

## β版について

本バージョンは研究開発・授業実践のための**公開β版**です。授業での実用を優先しながら継続的に改善しています。

現時点の主な確認事項・制約：

- UniDic連携は利用者側で公式 `lex.csv` の設定が必要です。
- PDF.jsは外部CDNを利用します。
- ブラウザ・OS・ローカルフォント環境によって表示差が生じる場合があります。
- アクセント・無声化情報は教材データに依存します。自動補完結果は必要に応じて教師が確認・修正してください。
